# Public CLI bug board

Use GitHub Issues for QA.army CLI defects and capability requests.

An actionable bug includes:

1. `qa-army --version` output.
2. The exact command with every credential and private value redacted.
3. Exit code and safe JSON receipt.
4. Expected and actual behavior.
5. Operating system and Node.js version.

Use the capability-request template for a recognized `REQUEST_CAPABILITY`
receipt. Never attach WorkOS claim tokens, one-time codes, assertions, refresh
or access tokens, profile API keys, or private evidence URLs.
